Building the **AI Agent Experience (AX)** layer: the infrastructure stack that makes websites readable, actionable, and trustworthy for AI agents, LLMs, and autonomous crawlers.

Leading engineering at **[LOi](https://github.com/laofertairresistible)**. Focused on agentic systems, multi-agent orchestration, retrieval pipelines, and the open protocols defining how AI interacts with the web (MCP, A2A, llmstxt).

### Engineering and AI Projects

Fifteen open-source projects with reproducible experiments, tests, CI, and published releases. Each repository documents its methods, raw evidence, and limitations. Results apply to the evaluated fixtures and hardware.

| Project | What it explores |
| --- | --- |
| [citable-publication](https://github.com/lucioduran/citable-publication) | Reproducible publication checks and citation evidence. |
| [rag-evaluation-workbench](https://github.com/lucioduran/rag-evaluation-workbench) | Compare retrieval strategies with repeatable local evaluations. |
| [agent-replay-runtime](https://github.com/lucioduran/agent-replay-runtime) | Recover tool executions with event logs and idempotency-aware replay. |
| [agent-injection-evals](https://github.com/lucioduran/agent-injection-evals) | Measure prompt injection attacks and tool-policy defenses. |
| [mcp-contract-harness](https://github.com/lucioduran/mcp-contract-harness) | Verify MCP negotiation, pagination, cancellation, and errors across clients. |
| [llm-serving-bench](https://github.com/lucioduran/llm-serving-bench) | Measure streaming inference latency, throughput, and memory on local hardware. |
| [citation-grounding-checker](https://github.com/lucioduran/citation-grounding-checker) | Evaluate whether cited passages support, contradict, or leave claims unresolved. |
| [chunking-ablation-suite](https://github.com/lucioduran/chunking-ablation-suite) | Compare fixed, structural, and semantic chunking with retrieval evidence. |
| [vector-search-portability](https://github.com/lucioduran/vector-search-portability) | Compare vector engines against exact neighbors and equivalent filters. |
| [reranker-budget-router](https://github.com/lucioduran/reranker-budget-router) | Evaluate reranking decisions against quality, latency, and compute budgets. |
| [bilingual-retrieval-evals](https://github.com/lucioduran/bilingual-retrieval-evals) | Evaluate English and Spanish retrieval across languages, entities, and accents. |
| [incremental-rag-index](https://github.com/lucioduran/incremental-rag-index) | Verify incremental index updates, deletions, and crash recovery against full rebuilds. |
| [structured-output-contracts](https://github.com/lucioduran/structured-output-contracts) | Check schema validity, semantic accuracy, and retries across local models. |
| [ai-model-routing-policy](https://github.com/lucioduran/ai-model-routing-policy) | Compare model routing with quality, cost, latency, and outage evidence. |
| [llm-semantic-cache](https://github.com/lucioduran/llm-semantic-cache) | Measure exact and semantic caching with user, permission, date, and version boundaries. |

### AX Toolkit

Open-source suite for making the web AI-agent-ready:

| Tool | What it does | |
|---|---|---|
| [**ax-skill**](https://github.com/lucioduran/ax-skill) | Claude Code skill : build AX-optimized sites from the first line of code | `/ax` in Claude Code |
| [**ax-init**](https://github.com/lucioduran/ax-init) | Scaffold all missing AX files for any project in seconds | `npx ax-init` |
| [**ax-cite**](https://github.com/lucioduran/ax-cite) | Web component for AI-extractable citation blocks | `npm i ax-cite` |
| [**ax-web-readiness**](https://github.com/lucioduran/ax-web-readiness) | AX audit dataset of the top 10K websites | [Hugging Face](https://huggingface.co/datasets/lucioduran/ax-web-readiness) |
